alto의 앱 다운로드

alto가 만든 Windows PC용 앱들을 배포하는 곳입니다.
개발자 스스로가 기존 상업적 앱들에 불만족해서 만든 앱들이며, 비상업적으로 배포하는 것이 기본적인 제 입장입니다. 계속 무료로 운영할 예정입니다만, altosMEMO 같이 클라우드를 사용하는 앱은 사용자가 늘어나면 재고할 수도 있을 것 같습니다.

1. NO 인스톨: 다운로드하신 파일이 바로 실행파일입니다. 이 앱들은 설치가 필요 없습니다. 지저분한 찌거기가 남는 설치 방식을 개인적으로 싫어합니다.
2. NO 광고: 어떤 광고나 상업적 장치도 없습니다.
3. NO 정보수집: 어떤 정보도 사용자 시스템으로부터 수집하지 않습니다. 로그인이 필요한 앱은 오로지 이메일 정도만 수집합니다.

윈도우용 서명이 없어 윈도우에서 '보안 경고', '게시자 알 수 없음' 등의 경고가 뜰 수 있습니다. 경고창의 '추가정보 - 실행'을 통해 실행해야 할 수도 있습니다. 항상 최고 모델의 AI들을 이용해 보안 문제가 없도록 여러 번 감수해 배포합니다. 사용 중 문제가 있으면 아래 연락처나 메시지 란에 의견을 보내주세요. 실시간으로 대응은 하지 못하지만 최대한 빠르게 업데이트 하겠습니다.
