# SKIN-CODE 배포 채널

이 저장소에는 **만들어진 실행파일과 버전 정보만** 있습니다. 각 앱의 소스는 별도 비공개
저장소에 있습니다.

## 구조

```
<앱이름>/manifest.json       현재 최신 판 정보 (버전·주소·크기·SHA-256)
<앱이름>/manifest.json.sig   위 파일에 대한 서명
```

실행파일은 깃이 아니라 **Releases 첨부**에 있습니다. 태그 규칙은 `<앱이름>-v<버전>`입니다.

## 무결성

`manifest.json`은 개인키로 서명되어 있고, 각 앱에는 짝이 되는 공개키가 들어 있습니다.
서명이 맞지 않으면 앱은 그 정보를 **버립니다**. 이 저장소가 뚫려도 사용자 PC에서 남의
코드가 실행되지 않게 하기 위한 장치입니다.

내려받은 실행파일은 `manifest.json`의 크기와 SHA-256으로 다시 대조합니다.
