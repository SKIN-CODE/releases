# WinSnapLayout

Windows의 여러 모니터에 열린 창을 배치하고, 9개 슬롯에 저장·복원하는 프로그램입니다.

**현재 버전: 0.2.4** · Windows 10/11 · 32비트/64비트 공용 · 별도 설치 과정 없음

[WinSnapLayout 0.2.4 내려받기](https://github.com/SKIN-CODE/releases/releases/download/winsnaplayout-v0.2.4/WinSnapLayout-0.2.4-win-anycpu.zip) · [배포 파일과 검증 정보](https://github.com/SKIN-CODE/releases/releases/tag/winsnaplayout-v0.2.4)

## 설치와 업데이트

ZIP을 계속 사용할 폴더에 풀고 `WinSnapLayout.exe`를 실행합니다. `readme.txt`와 `VERSION`도 같은 폴더에 보관합니다. 설정은 실행 폴더의 `config.json`에 저장하므로 쓰기 가능한 폴더를 사용합니다. 처음 실행할 때 Windows 시작 프로그램에 등록합니다.

0.2.0 이상은 앱 시작 시 최신 버전을 확인하며, 트레이 또는 편집기의 **업데이트 확인**으로 직접 실행할 수도 있습니다. 새 버전은 검증 후 교체·재시작합니다. 미저장 편집이 있으면 설치를 보류합니다. 0.1.0 및 이전은 트레이에서 종료한 후 ZIP을 한 번 직접 덮어씁니다. 기존 `config.json`을 유지합니다. 사용자 PC에는 GitHub 토큰이 필요하지 않습니다.

트레이의 **업데이트 확인 (0.2.4)**, 편집기 버튼 옆 **현재 버전: 0.2.4**에서 실행 버전을 확인합니다.

## 자동 편집

- 슬롯을 열면 저장한 위치와 크기를 그대로 표시합니다. 실행하지 않은 저장 앱도 편집할 수 있습니다.
- 수동 저장 앱이 있는 모니터의 첫 자동 편집은 그 모니터의 전체 앱 위치로 행·열을 구성하고 각 분할을 1/n로 만든 뒤 새 동작을 적용합니다. 다른 모니터는 유지합니다. 모니터 간 이동은 출발·도착만 편집합니다.
- 자동 편집으로 저장한 비율은 다시 열어도 이어갑니다. 단축키로 수동 저장하면 다음 자동 편집에서 해당 모니터를 다시 균등화합니다. 출처 정보가 없는 기존 설정도 첫 편집 전에는 저장 좌표를 유지합니다.
- 보관함 왼쪽의 **앱 크기 확대**, **앱 크기 축소**, **빈칸 놓기** 카드를 끕니다. 크기 조절은 해당 축의 이웃과 나누며 분리 가능한 다른 행·열은 유지합니다. 좌우 경계는 가로, 위아래는 세로 축을 선택합니다.
- 빈칸은 앱 상하좌우·내부와 모니터 네 경계에 삽입합니다. 모니터 경계는 전체 폭의 행 또는 전체 높이의 열을 추가합니다. 배치된 빈칸도 이동·확대·축소하며 굵은 점선을 유지합니다.
- 보관함으로 내린 앱은 기본 크기 몫으로 초기화합니다. 재삽입한 행·열은 1/n로 나눕니다. 더미 기능은 드래그 중 고정됩니다.
- 놓기 전에 결과를 미리 확인합니다. Esc·캡처 상실·유효하지 않은 드롭은 원본을 유지합니다. 실제 창은 **레이아웃 저장 및 적용**에서 움직입니다.

빈칸 객체와 트리는 저장하지 않고 실제 앱의 좌표를 저장합니다. 빈 영역이 다시 열기에서 독립 빈칸 카드로 항상 복원되지는 않습니다. 크기 조절은 상대 비율 방식이며 반대편 경계를 고정하는 픽셀 드래그는 아닙니다.

## 단축키

| 입력 | 동작 |
|---|---|
| Ctrl + Alt + A | 자동 레이아웃 편집기 |
| Ctrl + Shift + Alt + 1~9 | 현재 화면을 해당 슬롯에 수동 저장 |
| Ctrl + Alt + 1~9 | 해당 슬롯 복원 |
| Shift + 실제 창 경계 드래그 | 연결된 경계의 창들 수동 조절 |
| Ctrl + 실제 창 경계 드래그 | 마주 보는 두 창 수동 조절 |

수동 조절 후 저장 단축키로 다시 저장합니다. 편집기가 열려 있으면 저장·복원 단축키는 무시합니다.

## 검증과 배포 정보

레이아웃·화면 40개 시나리오 23,397개 조건, 업데이트 교체·복구 93개 조건, 배포 실패·복구 12개 조건을 통과했습니다. 독립 감사의 추가 288개 배열·해상도 조합에서도 분리 가능한 다른 행·열의 좌표 변화는 0건입니다. 게시 후 생산 업데이트 코드로 공개 피드·ZIP을 토큰 없이 내려받아 해시·크기·실행 파일 일치를 확인했습니다.

실제 운영 앱의 OS 마우스 전달·앱별 최소 크기·고 DPI 실행은 격리 검증 범위에 포함하지 않습니다. 루트 사용 설명서는 이번 배포에서 변경하지 않았습니다.

제품 전용 `manifest.json`이 최신 버전·다운로드·ZIP 크기·SHA-256·소스 commit의 기준입니다. 공유 저장소의 `releases/latest`는 사용하지 않습니다. ZIP에는 exe·readme.txt·VERSION만 포함하며 사용자 설정·로그·소스는 배포하지 않습니다.
