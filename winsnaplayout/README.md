# WinSnapLayout

Windows의 여러 모니터에 열린 창을 배치하고 9개 슬롯에 저장·복원합니다.

**현재 버전: 0.2.5** · Windows 10/11 · 32비트/64비트 공용 · 별도 설치 없음

[WinSnapLayout 0.2.5 내려받기](https://github.com/SKIN-CODE/releases/releases/download/winsnaplayout-v0.2.5/WinSnapLayout-0.2.5-win-anycpu.zip) · [릴리스와 검증 정보](https://github.com/SKIN-CODE/releases/releases/tag/winsnaplayout-v0.2.5)

## 설치와 업데이트

ZIP을 계속 사용할 폴더에 풀고 `WinSnapLayout.exe`를 실행합니다. readme.txt·VERSION도 같은 폴더에 둡니다. 설정은 실행 폴더의 config.json에 저장하므로 쓰기 가능한 폴더를 사용합니다. 처음 실행할 때 Windows 시작 프로그램에 등록합니다.

0.2.0 이상은 시작 시 또는 트레이·편집기의 **업데이트 확인**으로 최신 버전을 내려받아 검증 후 교체·재시작합니다. 미저장 편집이 있으면 설치를 보류합니다. 0.1.0 및 이전은 트레이에서 종료한 후 ZIP을 한 번 직접 덮어씁니다. 기존 config.json은 유지합니다. 사용자 PC에는 GitHub 토큰이 필요하지 않습니다.

트레이 **업데이트 확인 (0.2.5)**, 편집기 **현재 버전: 0.2.5**에서 실행 버전을 확인합니다.

## 현재 배치를 유지하는 편집

- 슬롯을 열고 편집해도 저장한 위치·크기·빈 영역을 유지합니다. 실행하지 않은 저장 앱도 편집할 수 있습니다. 첫 편집에서 자동으로 전체를 균등화하지 않습니다.
- 가능한 앱 경계에 마우스를 놓으면 방향과 색상을 강조합니다. 그 경계를 끌면 반대편을 고정하고 맞닿은 이웃과만 공간을 나눕니다. 다른 행까지 바꿔야 하는 T자 경계나 겹침은 조절하지 않습니다.
- 보관함 왼쪽 **크기 확대**, **크기 축소**, **빈 칸 만들기**를 경계에 놓을 수도 있습니다. 확대·축소는 해당 축 작업 영역의 5%씩 움직이며 대상·이웃 50px 하한에서 멈춥니다. 다른 앱과 모니터는 유지합니다.
- 방향 강조 후 벡터 애니메이션으로 실제 변화 방향을 보여 줍니다. 더미 이동 안내는 해당 제목, **앱 또는 모니터의 경계에 놓으세요.**, **취소 esc** 세 줄만 표시합니다.
- 앱이나 빈칸을 기존 카드에 넣으면 그 카드만 절반씩 나눕니다. 모니터 외곽은 전체 행·열을 만들고 나머지 배치를 남은 영역으로 비례 조정합니다.
- 옮기거나 제거한 자리는 빈 영역으로 둡니다. 배치된 빈칸도 이동·크기 조절하며 굵은 점선을 유지합니다. 빈칸 객체는 저장하지 않고 주변 앱의 좌표로 빈 영역을 유지합니다.
- 전체 1/n 정렬은 **모니터 제목 우클릭 메뉴**에서 따로 실행합니다. 편집 중 지나간 모니터는 바꾸지 않으며 모니터 간 앱 이동은 출발·도착만 변경합니다.
- 미리보기는 원본을 바꾸지 않습니다. Esc·캡처 상실·거부된 동작은 취소합니다. 실제 창은 **레이아웃 저장 및 적용**에서 움직입니다.

## 단축키

| 입력 | 동작 |
|---|---|
| Ctrl + Alt + A | 편집기 열기 |
| Ctrl + Shift + Alt + 1~9 | 현재 화면 수동 저장 |
| Ctrl + Alt + 1~9 | 슬롯 복원 |
| Shift + 실제 창 경계 드래그 | 연결된 경계의 창들 수동 조절 |
| Ctrl + 실제 창 경계 드래그 | 마주 보는 두 창 수동 조절 |

편집기가 열려 있으면 저장·복원 단축키는 무시합니다. 실제 창을 수동 조절한 뒤에는 저장 단축키로 다시 저장합니다.

## 검증과 배포 기준

현재 레이아웃·UI 34개 시나리오 9,107개 조건, 업데이트 교체·복구 93개 조건, 배포 실패·복구 12개 조건이 통과했습니다. 실제 설정에서 창 제목을 제거한 11앱 좌표로 경계 판정·다른 앱 보존·취소·저장·재열기를 검사했고 독립 감사와 재감사를 마쳤습니다. 격리 UI에서 직접 경계 드래그와 연출도 확인했습니다.

게시 후 생산 업데이트 코드로 공개 피드·ZIP을 토큰 없이 내려받아 소스·해시·크기·실행 파일 일치를 확인했습니다. 운영 창의 최소 크기·전체 DPI 조합 검증은 별도 범위입니다. 루트 사용 설명서는 이번 배포에서 변경하지 않았습니다.

이 제품의 manifest.json이 현재 버전·다운로드·ZIP 크기·SHA-256·소스 commit의 기준입니다. 공유 저장소의 releases/latest는 사용하지 않습니다. ZIP에는 exe·readme.txt·VERSION만 포함하고 개인 설정·로그·소스는 배포하지 않습니다.
