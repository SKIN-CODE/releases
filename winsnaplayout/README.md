# WinSnapLayout

Windows의 여러 모니터에 열린 창을 배치하고, 9개 슬롯에 저장·복원하는 프로그램입니다.

**현재 버전: 0.2.0** · Windows 10/11 · 32비트/64비트 공용 · 별도 설치 과정 없음

[WinSnapLayout 0.2.0 내려받기](https://github.com/SKIN-CODE/releases/releases/download/winsnaplayout-v0.2.0/WinSnapLayout-0.2.0-win-anycpu.zip) · [변경 사항과 배포 파일](https://github.com/SKIN-CODE/releases/releases/tag/winsnaplayout-v0.2.0)

## 처음 사용하는 경우

1. 위 링크에서 ZIP 파일을 내려받습니다.
2. 계속 사용할 폴더를 만들고 ZIP을 풉니다. 예: `D:\2. Applications\WinSnapLayout`.
3. `WinSnapLayout.exe`를 실행합니다. 작업표시줄 오른쪽 트레이에 아이콘이 생깁니다.
4. `Ctrl+Alt+A`로 레이아웃 편집기를 엽니다.
5. 사용할 슬롯을 고르고 앱을 배치한 뒤 **레이아웃 저장 및 적용**을 누릅니다.

프로그램은 현재 실행 폴더에 설정을 저장하므로 파일을 쓸 수 있는 폴더에서 사용하세요. 처음 실행할 때 Windows 시작 프로그램에 등록하는 기존 동작을 유지합니다.

## 0.1.0 또는 이전 버전에서 0.2.0으로 업데이트

**0.1.0에는 앱 자체 업데이트 기능이 없으므로 0.2.0을 한 번 수동으로 설치해야 합니다.**

1. 트레이 아이콘을 오른쪽 클릭해 **종료**합니다. 편집기 창만 닫으면 프로그램은 계속 실행 중입니다.
2. 기존 폴더의 `config.json`을 따로 복사해 백업합니다.
3. ZIP을 기존 폴더에 풀고 `WinSnapLayout.exe`, `readme.txt`, `VERSION`을 덮어씁니다.
4. 기존 `config.json`은 그대로 둡니다. ZIP에는 설정파일이 들어 있지 않습니다.
5. 새 `WinSnapLayout.exe`를 실행합니다. 트레이 아이콘에 마우스를 올려 버전 `0.2.0`을 확인합니다.

## 0.2.0부터의 자동 업데이트

앱이 시작되면 최신 버전을 확인하고, 새 버전이 있으면 배포 파일을 내려받아 실행 파일을 교체한 뒤 다시 시작합니다. 이후 버전부터는 매번 ZIP을 직접 받아 교체할 필요가 없습니다.

- 지금 바로 확인하려면 트레이 아이콘을 오른쪽 클릭해 **업데이트 확인**을 선택하거나 편집기의 **업데이트 확인** 버튼을 누릅니다. 두 곳 모두 같은 업데이트 기능을 실행합니다.
- 편집기에 저장하지 않은 변경 사항이 있으면 업데이트 적용을 보류합니다. 편집 내용을 저장하거나 취소한 뒤 다시 확인하세요.
- 업데이트 과정에서도 기존 `config.json`과 저장된 배치를 보존합니다.

앱 실행과 공개 버전 확인·다운로드에는 GitHub 토큰이 필요하지 않습니다. 배포 작업용 토큰은 사용자 PC에 넣지 않습니다.

## 주요 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl+Alt+A` | 자동 레이아웃 편집기 |
| `Ctrl+Shift+Alt+1` ~ `9` | 현재 배치를 해당 슬롯에 저장 |
| `Ctrl+Alt+1` ~ `9` | 해당 슬롯 배치 복원 |

## 0.2.0의 변경 사항

- 시작 시 새 버전을 확인하고 자동으로 다운로드·교체·재시작합니다.
- 트레이 메뉴와 편집기에 **업데이트 확인**을 제공합니다.
- 미저장 편집이 있을 때는 업데이트 적용을 보류하고 기존 설정을 보존합니다.

0.1.0에서 추가된 편집 기능도 유지합니다.

- 보관함으로 내린 앱의 크기를 기본 한 몫으로 초기화합니다. 다시 올릴 때 해당 행·열을 1/n로 나눕니다.
- 모니터를 선택해 **1/n 균등화**를 실행할 수 있습니다.
- 더미 아래에서 확대·축소·빈칸을 직접 선택할 수 있습니다.
- 드래그 중 대상 모니터·경계와 놓은 뒤의 배치를 미리 보여 줍니다.
- 버전 기준과 배포 파일의 SHA-256 확인값을 제공합니다.

기본 배치, 확대/축소 비율, 저장된 수동 배치는 서로 구분합니다. 기존 모든 앱을 다시 균등하게 만들려면 편집기 하단의 모니터 선택과 **1/n 균등화**를 사용하세요. 실제 창은 **레이아웃 저장 및 적용**을 눌러야 변경됩니다.

## 확인 범위

격리된 가상 창으로 편집·저장·복구 계산을 검사했습니다. **운영 편집기의 긴 IDE 창에서 더미 세 모드가 모두 무반응인 현상은 실제 마우스 입력으로 해결 여부를 확인하지 못했습니다.** 현재 버전이 이 현상을 해결했다고 단정하지 않습니다.

## 배포 파일과 최신 정보

실제 ZIP은 제품 전용 GitHub Release에 있습니다. 이 폴더의 `manifest.json`에는 최신 버전·다운로드 주소·ZIP 크기·SHA-256이 기록됩니다. 다른 앱의 최신 버전과 혼동하지 않도록 저장소 전체의 `releases/latest`는 사용하지 않습니다.
