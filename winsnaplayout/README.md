# WinSnapLayout

Windows의 여러 모니터에 열린 창을 배치하고, 9개 슬롯에 저장·복원하는 프로그램입니다.

**현재 버전: 0.2.2** · Windows 10/11 · 32비트/64비트 공용 · 별도 설치 과정 없음

[WinSnapLayout 0.2.2 내려받기](https://github.com/SKIN-CODE/releases/releases/download/winsnaplayout-v0.2.2/WinSnapLayout-0.2.2-win-anycpu.zip) · [변경 사항과 배포 파일](https://github.com/SKIN-CODE/releases/releases/tag/winsnaplayout-v0.2.2)

## 처음 사용하는 경우

1. 위 링크에서 ZIP을 내려받아 계속 사용할 폴더에 풉니다.
2. `WinSnapLayout.exe`를 실행합니다. `readme.txt`와 `VERSION` 파일도 같은 폴더에 보관합니다.
3. 작업표시줄 오른쪽 트레이에 아이콘이 생깁니다. `Ctrl+Alt+A`로 편집기를 엽니다.
4. 사용할 슬롯을 고르고 앱을 배치한 뒤 **레이아웃 저장 및 적용**을 누릅니다.

설정은 실행 파일과 같은 폴더의 `config.json`에 저장하므로 파일을 쓸 수 있는 폴더에서 사용하세요. 처음 실행할 때 Windows 시작 프로그램에 등록합니다.

## 업데이트

- **0.2.0 이상**: 앱 실행 약 2.5초 후 최신 버전 검사를 시작합니다. 새 버전이 있으면 내려받아 검증하고 자동 교체·재시작합니다. 완료 시간은 다운로드 속도 등에 따라 달라집니다.
- 지금 확인하려면 트레이의 **업데이트 확인** 또는 편집기 왼쪽 아래의 같은 버튼을 누릅니다.
- 미저장 편집이 있으면 적용을 보류합니다. 저장하거나 취소한 뒤 다시 확인하세요.
- **0.1.0 및 이전**: 트레이 메뉴에서 프로그램을 종료하고 `config.json`을 백업한 뒤 최신 ZIP의 실행 파일·설명서·VERSION을 기존 폴더에 덮어씁니다. 기존 `config.json`은 유지합니다.

업데이트는 기존 설정과 저장된 배치를 보존합니다. 앱 실행과 공개 다운로드에 GitHub 토큰은 필요하지 않습니다. 배포 ZIP에는 사용자 설정이 들어 있지 않습니다.

## 자동편집기 사용

- 왼쪽의 붉은 점선 카드 **앱 크기 확대**, **앱 크기 축소**, **빈칸 놓기**를 각각 끌어 사용합니다. 카드에는 기호 없이 이름만 표시하며 영문 이름은 두 줄입니다.
- 확대·축소 카드는 앱 또는 모니터 경계 띠에, 빈칸 놓기는 경계 띠를 피한 앱 카드 안쪽에 놓습니다. 놓기 전에 미리보기로 결과를 확인하세요.
- 카드의 기능은 드래그하는 동안 고정됩니다. 취소하려면 Esc를 누릅니다.
- 앱을 보관함으로 내리면 크기를 기본 한 몫으로 초기화합니다. 다시 올리면 해당 행·열 분할을 1/n로 나눕니다.
- 실제 창은 **레이아웃 저장 및 적용**을 눌러야 변경됩니다.
- 저장 후 실제 창 경계에서는 Shift로 연결된 경계의 창들을, Ctrl로 마주 보는 두 창을 조절할 수 있습니다. 조절 후 저장 단축키로 다시 저장합니다.

## 현재 버전 표시

- 트레이: **업데이트 확인 (0.2.2)** / **Check for updates (0.2.2)**
- 편집기 버튼 옆: **현재 버전: 0.2.2** / **Current version: 0.2.2**

실행 중인 앱의 세 자리 버전을 표시하며 네 번째 빌드 번호는 생략합니다. 자세한 한·영 사용법은 ZIP의 `readme.txt`에 있습니다.

## 주요 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl+Alt+A` | 자동 레이아웃 편집기 |
| `Ctrl+Shift+Alt+1` ~ `9` | 현재 배치를 해당 슬롯에 저장 |
| `Ctrl+Alt+1` ~ `9` | 해당 슬롯 배치 복원 |

## 0.2.2의 변경 사항과 확인 범위

- 더미 원본 카드에서 기호를 없애고 폭을 120px로 줄였습니다. 카드 사이 간격은 일반 앱과 같은 10px입니다.
- 더미 드래그 중 Shift·Ctrl 기능 전환과 관련 한·영 안내를 제거했습니다.
- 카드 3개, 균등화 컨트롤 숨김, 한·영 도움말 및 현재 버전 표시를 반영했습니다.
- 격리 레이아웃·화면 34개 시나리오 8,396개 조건, 업데이트·복구 93개 조건, 배포 실패·복구 12개 조건을 통과했습니다. 게시 후 실제 업데이트 코드로 공개 다운로드와 패키지 검증도 통과했습니다.

실제 운영 앱의 마우스 입력과 고 DPI 실행은 위 검증 범위에 포함하지 않습니다.

실제 ZIP은 제품 전용 GitHub Release에 있습니다. 이 폴더의 `manifest.json`에는 최신 버전·다운로드 주소·ZIP 크기·SHA-256이 기록됩니다. 저장소 전체의 `releases/latest`는 다른 제품이 사용하므로 WinSnapLayout의 버전 확인에는 사용하지 않습니다.
