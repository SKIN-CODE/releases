# altosPDF

altosPDF는 Windows에서 PDF를 보고 고치는 프로그램입니다.
Windows 10/11 64비트에서 동작합니다.

[최신 판 내려받기](https://github.com/SKIN-CODE/releases/releases/latest)

## 설치와 실행

설치 과정이 없습니다. 폴더를 하나 만들고 그 안에 `altosPDF.exe`를 두신 뒤
그대로 실행하시면 됩니다. 파일은 이것 하나뿐입니다.

새 판이 나오면 앱이 알려 드리고 스스로 바꿉니다. 다시 받으실 필요가 없습니다.

## 무엇을 할 수 있습니까

**문서를 봅니다.** 화면을 이어서 넘기고, 크기를 키우거나 줄이고, 한 쪽 또는 두 쪽을
나란히 봅니다. 글을 찾고, 목차로 이동하고, 필요한 쪽만 골라 인쇄합니다.

**페이지를 다시 짭니다.** 여러 문서를 함께 열어 쪽 순서를 바꾸고, 돌리고, 지우고,
필요한 쪽만 뽑아냅니다. 되돌리기를 50번까지 할 수 있습니다. 암호를 걸고 인쇄나
복사를 막을 수도 있습니다.

**문서를 고칩니다.** 형광펜을 긋고 지웁니다. 본문의 글자를 눌러 바로 고칩니다.
고친 글자는 원래 글꼴과 크기, 색을 그대로 씁니다.

## Windows에 등록되는 것

처음 실행하면 기본 PDF 앱으로 지정할지 묻습니다. **'예'를 누르셔야 Windows 설정
창이 열립니다.** 앱이 기본 프로그램을 마음대로 바꾸지는 않으므로, 그 창에서 PDF를
altosPDF로 직접 골라 주셔야 합니다. '아니오'를 누르면 다음에 또 묻고, '취소'를
누르면 다시 묻지 않습니다.

실행할 때마다 지금 실행파일이 있는 자리를 사용자 계정에 적어 두고, 탐색기에서 PDF를
오른쪽 단추로 눌렀을 때 나오는 **편집·병합** 메뉴를 넣습니다. 그래서 실행파일을 다른
폴더로 옮기셨다면 **새 자리에서 한 번 실행해 주십시오.** 적어 둔 자리가 그때 갱신됩니다.

지우실 때는 순서가 있습니다. 앱의 설정에서 **'Windows 통합 제거'를 먼저 누르시고**
그다음에 파일을 지우십시오. 파일부터 지우면 등록해 둔 내용이 컴퓨터에 남습니다.
제거한 뒤에 앱을 다시 실행하면 되살아나므로, 제거하고 나서는 실행하지 마십시오.

## 미리 알아 두실 점

PDF는 글을 담아 두는 형식이 아니라 **화면에 무엇을 어디에 그릴지 적어 둔 그림 명령**의
모음입니다. 그래서 모든 문서의 모든 글자를 다 고칠 수는 없습니다.

- 그림과 글자가 겹쳐 있거나 짜임이 복잡한 쪽은 글자를 고치지 못할 수 있습니다.
  이런 쪽을 여시면 화면 위쪽에 한 줄로 알려 드립니다. 보기와 다른 기능은 그대로 됩니다.
- 만든 프로그램이 글자를 특이하게 담아 둔 문서는 원래 글을 되살릴 수 없어 고치기가
  막힙니다. 문서를 열어 보시기 전에는 알 수 없습니다.
- **전자서명이 든 문서를 고치면 서명이 깨집니다.** 이는 PDF 규격상 어쩔 수 없습니다.
  서명을 지켜야 하는 문서는 고치지 마십시오.
- 문단 전체가 다시 흐르는 편집은 하지 않습니다. 글자 수가 크게 늘면 줄을 넘지 못하고
  뒤쪽 글자와 겹칠 수 있습니다.

고칠 수 없는 글자는 **저장하기 직전에 알려 드리고 저장을 멈춥니다.** 화면에 보여 드린
모습과 다르게 저장되는 일은 없습니다.
